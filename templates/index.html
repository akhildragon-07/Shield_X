# Email Address Status Mail Server (MX) Diagnostic Details

Understanding the Classifications

How this tool categorizes each address safely and conservatively.

Likely deliverable

Syntax is valid, authoritative DNS MX records exist, and the mail server positively acknowledged the recipient address (status 250).

Safe to send. Note: final delivery still depends on spam filters and mailbox quotas.
Likely to bounce

Syntax is broken, domain does not exist (NXDOMAIN), has no mail exchanger records, or the mail server explicitly rejected the mailbox (status 550).

Do not send. This address has a very high probability of hard bouncing.
Unknown

Domain has working mail servers, but mailbox existence could not be confirmed because the server conceals recipient info, timed out, or port 25 is blocked.

Conservative classification. Use double opt-in verification or check manually.
Privacy Guarantee: All checks are performed in-memory during the request. Addresses are never saved to a database, persisted in logs, or shared. No actual email messages are sent.
