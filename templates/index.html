# Email Address Status Mail Server (MX) Reason & Diagnostic Details

How to Interpret Deliverability Classifications

Likely deliverable

The email address passed syntax validation, authoritative DNS MX records were resolved, and the recipient mail server responded positively during validation handshake.

Delivery is probable, but spam filters or end-user quota policies can still cause rejection.
Likely to bounce

The address format is syntactically invalid, the recipient domain does not exist in DNS (NXDOMAIN), lacks mail servers, or the mail server explicitly rejected the recipient mailbox (e.g. 550 Mailbox not found).

Sending to this address carries a high risk of hard bounce.
Unknown

The domain has valid mail servers, but mailbox existence could not be confirmed. Common reasons include: server greylisting, anti-spam protections hiding recipient status, connection timeouts, or outbound port 25 blocking by hosting providers.

Exercise caution or perform double opt-in verification.
