# Email Status Mail Server Details

What the statuses mean

Likely deliverable

The email format is valid, domain has working MX servers, and the mail server gave a positive response during check. Delivery is probable, though internal spam filters or user storage limits can still affect it.

Likely to bounce

The address format is bad, the domain does not exist (NXDOMAIN), has no mail servers configured, or the mail server explicitly rejected the recipient mailbox (e.g. 550 User Unknown).

Unknown

The domain is real and has mail servers, but mailbox existence could not be confirmed because the server hides recipient status, timed out, greylisted the probe, or port 25 is blocked by hosting.

Privacy Note: Emails entered here are checked in memory and are never saved to a database or written to log files. This tool never sends actual emails.
